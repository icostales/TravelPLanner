Connect Google Sheets

TrailPlan uses a Google Sheet as its database through a Google Apps Script web app. Until connected, your demo plans stay in this browser only.

Quick Setup

  1. Create a blank Google Sheet.
  2. Open Extensions > Apps Script and paste apps-script/Code.gs.
  3. Run setupSheets once and approve access.
  4. Deploy as a web app: Execute as: Me and Who has access: Anyone.
  5. Paste the deployment URL here and click Connect.

The script creates database tabs for Trips, Itinerary, Expenses and Packing. Keep the web app URL private because it can write to your travel data.

Using Another Device?

  1. Open this TrailPlan app on that device from a hosted website or a copy of the app files. A local file:///D:/... address exists only on this computer.
  2. Paste the same Apps Script /exec URL on every device. The connection is saved per browser, not in Google Sheets.
  3. Test the /exec URL in the other device's browser. It should display JSON starting with {"ok":true. If Google requests access or denies it, update the deployment permissions above and deploy a new version.
